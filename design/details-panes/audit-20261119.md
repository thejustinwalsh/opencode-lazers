# LAZERS details-pane audit (evidence only, no redesign)

Date: 2026-11-19. Live app: OpenCode Desktop, project opencode-lazers. Window 1383x868 px.

## Method and limits (read first)

- Live capture used `app_screenshot`/`app_zoom` only. The accessibility tree withholds text titles (every text node reads "title withheld"), so exact transcription is from screenshots, and **all word/line counts are estimates** from the transcribed screens plus the JSX. Treat them as +/-15%.
- Background scrolling in the OpenCode webview works only intermittently, so some tails were not reached. Each is marked.
- Default pane: `DETAILS_DEFAULT_SIZE = 0.45` of the container (src/details-pane.ts:6). In this window the body is about 330 px tall (about 17 text lines). "Screenfuls" below are expanded height / 330 px. The pane is closed until the user opens it; "Selecting an item never opens it" (src/details-pane.tsx:11), so by default only the 32 px header bar is visible.
- "Seen" = live screenshot. "Source" = read from JSX, not seen.
- Not done: no button was clicked that acts (Assign, Save, Revert, Open task, Open Architect, Retry, Recapture history, Start). Only selection, tabs, view filters, disclosures. I dragged the splitter to enlarge the pane in some captures; it reverted to its default on its own.
- Live state at capture: Architect idle, 1 running (LZ-232), 3 needs you, 1 failed, 8 queued, 26 idle hidden. Tasks: 26 open (all "Waiting"/paused/clock icons). No task was accepted, failed or running in the Tasks list, and I could not change the Tasks row selection in the background (AXSelected "ineffective"), so only LZ-232 was captured live. Other states are from source.

## Recurring patterns (stated as facts)

1. **The same sentence is shown 3-5 times in one view.** Tasks objective: list row, bar, h3, objective paragraph, Full-spec JSON. Radar session title: list row, bar, body h3. Radar group nodes: node label, bar, body h3, `Queued 8` row. Trajectory: model, start time, call count and event count each shown in the page top and again in the pane.
2. **The bar header and the body h3 duplicate each other** (Radar 1.1, 1.4, 1.2; Tasks 3.1; Models assignment: `UI openai/gpt-6-luna · max` + Model select).
3. **Cost/price panes state the same disclaimer repeatedly and show many different totals.** Trajectory: `not a provider invoice` 3 ways; Models: 5 dollar figures for one model, 7-9 decimal places.
4. **Raw identifiers in view**: UUIDs, `ses_` ids, 40- and 64-char hashes, absolute paths (twice), ISO and locale timestamps for the same instant, snapshot ids, column names (`runner_attempt.started_at`), tier ids (`prompt-272000;utc-none-none:1`).
5. **Internal state-machine / event names shown untranslated**: READY, DISPATCH, CONTEXT_RESOLVED, EFFECT_INTENDED, worker-execution-outcome, `Recorded lifecycle running`, `Worker outcome interrupted`, `Membership · cohort-effort`, `exact-native-model-quote`.
6. **Conflicting state words in one place**: Tasks shows Waiting / on hold / recorded running / Worker inactive / interrupted; Radar calls the same task running; Trajectory shows `$0.031` next to `1 unpriced`, `price missing`.
7. **Disclosures hide the useful part and also hide the walls.** The reason a task is blocked is under `Details > Lifecycle`/`Activity`; the walls (JSON spec, 165+76 events, 24 sentences of cost notes) are also disclosures, so one expand-all multiplies the pane 10-20x. 8. **Selecting a small thing shows the large parent report below it.** Trajectory: selecting one 25 ms tool call keeps the whole attempt usage/estimate/activity under it. Models: selecting a task inside a model's pane keeps the model report.
9. **Heading-less lead blocks.** Bold title with no label (Tasks h3, Radar h3), facts lines of dot-separated fragments (`Priority 1 · ... · step 1`, `gpt-6-luna · max attempt 1 started 12:58 PM last activity 1d ago`), stat rows with no heading (Models, Trajectory).

11. **Empty and zero states are rendered at full structure**: `Calls 0 | Files 0 | Messages 0`, `Files touched 0`, `Tokens`/`Accepted` columns blank for every catalog model, `0 records` source card, blank path for grep.
12. **Pluralization/typos**: `1 retries`, `1 recorded attempts · 1 sessions`, `1 accepted tasks`, `1 observation(s)`, `runtime.ts12821+`, `gpt-5.5_unknown`.
13. **Pane is closed by default and the bar is one 32 px line**, so a user who does not open it sees only the repeated title; once opened at about 330 px, the top of every pane is a lead (title/facts/state) of 100-250 px and the first screen rarely includes the second section.
