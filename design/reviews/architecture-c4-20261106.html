LAZERS is one plugin package hosted inside OpenCode. This view shows responsibility, not separate deployable daemons.

Blue = OpenCode-owned; purple = LAZERS-owned. LAZERS components run in existing service, renderer and main processes; arrows identify transport and timing.

TaskRuntime owns state; native sessions own execution facts. Separate histories and projections retain provenance. Recovery handoff library is currently unregistered, so it has no runtime arrow.

Repeated nodes identify the same authority as the orchestration view. Recovery facts are an append-only change projection; the handoff library has no registered production producer or consumer.

Main-process disk lease and renderer GPU lifetime protect different resources. Broker delivery, lease acquisition and disposal receipts are distinct protocols. No claim that observed UI freezes came from GPU.
