# LAZERS 0.2.1

This patch repairs task scheduling, retained work cleanup, local inference reconnection and analysis memory release. Semantic review remains in development for 0.3.0 and is not included.

- Idle workers release their delegated-agent slots and reacquire them before a resumed model request. Queued tasks do not consume active-worker capacity.
- Capacity uses the same project pool across canonical and worktree identities.
- Architect revisits unresolved blocked plans and accepted work after a delivered notification. Pending human questions remain undisturbed.
- Idle review lookups no longer open write transactions.
- Completed WASM analysis releases retained memory and bindings.
- Local inference reconnects after idle provider release while preserving active model ownership.
- Panels can read historical sessions after their worktrees are removed.
- Cleanup recognizes settled superseded checks without discarding dirty or unmerged work.

## Install

```sh
opencode plugin add opencode-lazers@0.2.1
```

Restart OpenCode Desktop and its service. Keep one LAZERS installation configured.

The plugin SDK remains pinned to OpenCode 2.3.0. The recorded regular Desktop checks used OpenCode 2.4.1; this is not a compatibility guarantee for other versions.
