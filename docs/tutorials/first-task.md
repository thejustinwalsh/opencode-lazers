# Complete your first task

Install [LAZERS v0.1.0](../how-to/install.md), then restart OpenCode Desktop and its service.

1. Open a project in OpenCode Desktop.
2. Start a session in that project.
3. Select **Architect** from the agent list.
4. Describe one small change and its expected result.

For example, ask: “Add a clear empty state to a list. Show ‘No tasks yet.’ Keep the existing actions. Add a focused behavior check.”

Architect inspects the project and defines the task plan. Architect asks a focused question when a missing choice changes requirements, scope, acceptance, or checks.

The runtime admits the plan and starts eligible work after Architect requests dispatch. Open **Tasks** from the session panel menu, or run `/lz-tasks`, to follow progress.

Read Architect’s final report. Review the changed files and checks. Architect can integrate authorized work. You decide when to publish the result.

See the [user controls reference](../reference/user-controls.md) for Tasks, Radar, Trajectory, and Models.
