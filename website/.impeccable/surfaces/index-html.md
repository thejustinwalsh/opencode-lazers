# Surface: LAZERS marketing site (index.html)

Mode: Persuade. Build path: code-led (no image generation on this machine); `design/magazine-modern.png` is the critique reference, `design/magazine-original.png` the density reference.

Audience: OpenCode users deciding whether LAZERS fits. Job: understand the loop, trust it, install v0.1.0. Proof: the docs' own mechanics (acceptance separate from worker reports, recorded checks and attempts, unknown costs stay unknown). Constraints: real HTML type and controls, reduced-motion parity, links Docs / GitHub / Install accurate, no invented claims.

## Direction contract

THESIS: A 1990s console-magazine cover for a developer tool. The cover lines are the product's four parts, and the cat's eye beams tie the cover to each feature spread as it enters. Refuses the category default: centered hero, gradient, three icon cards, terminal screenshot.

OWN-WORLD: Cool ivory paper, deep ink-indigo slabs and heavy rules, periwinkle halftone dot fields, magenta and cyan used only as signal: beams, speed stripes, rules, CTA. Wide black italic wordmark with ink double outline and magenta halftone fill; condensed heavy italic headlines; plain grotesk body. Pixel marks (flag, sparkle, stripes, halftone corner) rendered pixelated. Skewed slab blocks; column rules like a contents grid.

STORY: LAZERS turns a feature request into tracked work in OpenCode. You set the goal; Architect plans; Scheduler admits and dispatches native workers; Radar watches live; Trajectory keeps attempts and checks. A worker report is not acceptance. Install v0.1.0.

FIRST VIEWPORT: At 1440: giant angled LAZERS top-left across ~60% width over halftone; ink slab top-right with Docs, GitHub, Install and a three-line italic tagline with stripes; cat bleeding off bottom-left at ~55% viewport height, paired magenta and cyan beams rising right behind copy; condensed headline plus Pretext lede wrapped to the cat contour centre-left; two-column contents grid right: Architect, Scheduler, Radar, Trajectory with marks and rules; skewed magenta INSTALL slab lower-right; ink band along the bottom with release facts.

FORM: magazine cover, contents, feature spreads, back-cover install. seed: none (pinned) "magazine-modern.png is the target for palette, scale and layout." Signature: one paired eye-beam volley per section entry, origins locked to measured pupil anchors.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
