# LZ-32 native screenshot review

**Blocking visual issue:** group fractions are unexplained and misleading in the new history views. In Completed, each visible accepted task sits under `0/1`; in Cancelled, one visible cancelled task sits under `1/1` while others show `0/1`. Source confirms these are active/total, not the visible filtered count, but that meaning is only in the accessible label. A sighted user can reasonably read them as completion or filter results. Simplest repair: hide these active/total fractions for non-Open filters, or explicitly label the numerator as active if it is needed there; retain meaningful accessible names. Do not silently redefine the fraction as completed without checking its source.

**Optional polish:** `Project · History` beside `State: Completed` or `State: Cancelled` duplicates and muddies the new independent dimensions; show `Project`/`Session` alone in the scope control and let the state control name the filter. It is not evidence of a scope malfunction. At ~330px the header wraps cleanly and the selected row/inspector remain readable; the two actions wrap onto two lines, which is acceptable. Long task row names truncate aggressively, but selection reveals the full objective immediately below, consistent with the reference's compact list; consider two-line rows later only if users cannot distinguish real records. The LZ-9 check command wraps over two lines and its status drops right; readable, though a tighter status line would improve balance. The large objective consumes more space than the concept's short title, but it is real content and does not obstruct the inspected timeline.

The selected row and horizontal inspector match the reference's quiet hierarchy, and both Trajectory captures show the intended task reference and attempt context. Controls and visible text stay inside the narrow pane. The open menu is legible, but these pointer captures do not demonstrate keyboard focus or focus return, so no focus pass is claimed from screenshots. Functional navigation/filter results are as reported by the driver; this review is visual only.
